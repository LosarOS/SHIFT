## Конфликты Studio — контролируемый тестовый профиль

Используйте копию данных и тестовый экземпляр виджета. Для конкурентного изменения применяйте разрешённый тестовый инструмент, не редактируйте живую SQLite вручную.

| Сценарий | Ожидаемое поведение | Результат |
| --- | --- | --- |
| Двигать/масштабировать виджет, сохранить из редактора | Новые настройки редактора защищены; конфликт виден | NOT VERIFIED |
| Удалить/скрыть/заменить экземпляр при открытом окне | Фоновая запись не воскрешает и не заменяет экземпляр | NOT VERIFIED |
| Edit/Desktop при конфликте расположения | Неприменённая геометрия не становится подтверждённой | NOT VERIFIED |
| «Собрать» после редактора размера/topmost/режима | Новая позиция на доступном экране, остальные актуальные свойства сохранены | NOT VERIFIED |
| Маленький экран → большой экран | Временный clamp не теряет preferred size | NOT VERIFIED |
| Несколько циклов apply/edit/autosave | LastApplied не вызывает конфликты конфигурационной ревизии | NOT VERIFIED |
| Notes/Timer при конфликте геометрии | Их состояние сохраняется отдельно, потеря текста не скрывается | NOT VERIFIED |
| Restart при нерешённом конфликте/незавершённом apply | Нет скрытого повторного запуска или применения обоев | NOT VERIFIED |

## Доступность и физическая Windows

Проверить Windows 11 и поддерживаемую Windows 10 build19041+; DPI100/125/150/200%, крупный системный текст, Narrator, High Contrast, reduced motion. Все новые диалоги: порядок Tab, доступные имена/выделение, Enter/Escape, читаемые ошибки, отсутствие обрезанного текста.

Системная матрица Studio остаётся в [протоколе Studio](RC5-MANUAL-ACCEPTANCE-RU.md): разные мониторы/DPI, hotplug, sleep/resume, RDP, fullscreen, z-order, установленная Studio. Успех одного disposable Windows Server runner не закрывает эти пункты.

Записывайте версию ОС/сборки, DPI, мониторы, шаги, результат, снимок/лог и точный source commit. Не заменяйте неисполненный сценарий словом PASS.
