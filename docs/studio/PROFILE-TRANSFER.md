# ADR: перенос конфигурации Studio и снимки заметок

Статус: принято для RC5. Применение и runtime подтверждаются отдельным Windows validation report.

## Решение

Профиль переносится как декларативный UTF-8 JSON `SHIFT.StudioProfile`, schema1. Формат имеет собственные DTO вместо сериализации SQLite/domain objects. Пакет содержит один профиль, использованные определения и экземпляры с нормализованной геометрией. Общие определения сохраняют общность через локальные числовые ключи, а исходные GUID, ревизии и monitor IDs не экспортируются.

Обои, внешние файлы, workspace binding, автоматическое применение, runtime-заметки/таймеры, consent, settings и recovery journals исключены из схемы. Начальный текст шаблонов — отдельный opt-in, выключенный по умолчанию. Названия и описание остаются пользовательским содержимым: перед передачей нужно проверить предпросмотр.

Это перенос конфигурации, а не полный backup. Добавление изображений в архив потребует отдельного решения о managed resources, ссылках, лицензиях, размерах и согласованности с recovery. Для полной копии пользователь по-прежнему сохраняет весь каталог данных после выхода из SHIFT.

## Границы и доверие

- Не более 2МиБ UTF-8, 64 экземпляров/определений и глубины JSON16.
- Запрещены неизвестные и повторяющиеся поля, числовые enum values, неподдерживаемые версии и некорректные ссылки.
- Domain validation проверяет шрифты, цвета, размеры, длительности, заметки и нормализованные координаты. UTF-8 BOM принимается; другие кодировки не угадываются.
- Импорт создаёт новые IDs, сбрасывает активность/привязки и возвращает inert draft. Окна начинают с Edit Mode, обычным z-order, без click-through.
- Сохранение использует существующий `IStudioPresetStore.SavePresetAsync`: одна insert-only SQLite transaction; коллизия или поздняя ошибка откатывает весь пакет. SQLite schema остаётся2.
- Review/Back/Cancel не пишут данные. Save не включает Studio и не вызывает wallpaper adapter, widget runtime или launch coordinator. Apply остаётся отдельным пользовательским действием.
- Строгая схема намеренно отклоняет будущие неизвестные конструкции вместо их тихой интерпретации. При расширении формата нужно явное версионирование.

## Экспорт заметок

`StudioNotesExport` строит обычный читаемый текст. Состояния связываются по InstanceId, потому что две заметки могут использовать одно определение. Сохранённая пустая строка не заменяется InitialNotes. Скрытые экземпляры включаются с пометкой; если состояния ещё нет, используется подписанный начальный текст.

Presentation читает сохранённые состояния, затем накладывает read-only `CaptureLiveStatesAsync` выбранного активного профиля. Для открытых окон экспортируется фактический текст даже при конфликте или недоступности записи. Экспорт не требует успешного flush; не выполняет разрешение конфликтов и не читает неоткрытые recovery drafts. Уже открытый preview — снимок, а не бесконечно обновляемая подписка.

Файл записывается UTF-8 без BOM через временный файл в выбранном каталоге, flush и замену целевого пути. Копирование в clipboard происходит только по кнопке. Файл, предпросмотр и clipboard не являются шифрованным хранилищем. Объём текста ограничен 8МиБ.

## Проверка

Core tests покрывают границы, Unicode, приватность, общий definition graph, отсутствие мутаций, свежие IDs, независимые импорты, откат транзакции и сохранность owner data. Native UIA проверяет реальные dialogs/clipboard/file pickers, invalid/review/cancel/save и неизменные активные HWND. Полная физическая Windows/DPI/accessibility приёмка — отдельный gate; наличие документа его не заменяет.
