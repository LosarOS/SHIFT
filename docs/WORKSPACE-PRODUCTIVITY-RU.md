# Рабочие пространства RC7: список и план запуска

## Добавить несколько элементов

Откройте пространство и нажмите «Вставить список».

1. Выберите общий тип: ссылки, приложения, папки или файлы. Для смешанного набора добавьте несколько отдельных списков.
2. Вставьте один полный путь или HTTP/HTTPS адрес на строку. Разрешены внешние кавычки вокруг пути; аргументы приложения не угадываются.
3. Нажмите «Проверить формат». Исправьте ошибки, снимите ненужные строки. Повторы существующих целей и предыдущих строк не добавляются.
4. Задайте общую задержку и при необходимости включите «Включить новые элементы для будущего запуска». По умолчанию новые элементы **выключены**.
5. Нажмите «Добавить выбранное». Новые строки дополняют текущий набор в порядке исходного списка. Ничего не запускается.

«Назад к списку» сохраняет введённый текст для исправления. «Отмена» закрывает без записи. Если пространство изменилось после предпросмотра, сохранение отклоняется: откройте диалог заново.

Лимиты: до 100 непустых строк за раз, 65536 символов ввода, максимум 100 элементов на пространство. Задержка 0–300000 мс на добавляемый элемент.

Проверяется **формат**, а не наличие/доступность файла, содержимое ярлыка или готовность приложения. Сетевых запросов нет. После сохранения используйте «Проверку пространства». Команды, сценарии и параметры запуска добавляются отдельно через редактор, с обычными подтверждениями при запуске.

## Предпросмотр запуска

Нажмите «План запуска» на странице пространства. Он показывает:

- фактический порядок, включая выключенные шаги;
- количество включённых, пропущенных и командных элементов;
- оболочку команды — PowerShell или cmd;
- цель, параметры и рабочую папку;
- накопленную сумму настроенных задержек до каждого включённого шага;
- повтор одной цели/параметров среди включённых шагов.

Выключенные задержки не входят в сумму. Одинаковая цель с разными аргументами или оболочками не считается повтором. Регистр пути/query URL и credentials сохраняется; регистр host сравнивается без учёта различий.

План — снимок настроек. Он **не запускает** приложения, не выполняет команды и не создаёт историю. Он не измеряет время старта программ, длительность команд, готовность вкладок или ожидание согласия. «Проверить цели» открывает существующую диагностику; обычный запуск остаётся отдельной кнопкой и сохраняет consent flow.

## Studio и конфликт расположения

Фоновое сохранение геометрии больше не заменяет профиль целиком. Более новое положение, скрытие, удаление или замена экземпляра в редакторе защищены от старого окна.

При конфликте появляется пояснение. Чтобы принять сохранённый профиль — примените его заново. «Собрать виджеты» задаёт новое явное расположение на доступном экране, сохраняя актуальные размеры/topmost/режим. Переключение Edit/Desktop не принимает неприменённую геометрию за подтверждённую.

Заметки/таймер и расположение — разные данные. Нельзя считать сообщение о сохранении заметки подтверждением записи конфликтной геометрии. Не удаляйте экземпляр с нужными заметками без экспорта/backup.

## Обновление и границы проверки

Перед обновлением полностью выйдите из SHIFT и скопируйте весь каталог данных — включая Studio/Images, Studio/RecoveryNotes и migration-backups. SQLite schema 2 сохранена. Неподписанные EXE могут вызвать SmartScreen.
