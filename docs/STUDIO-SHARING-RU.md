# Перенос профилей Studio и сохранение заметок

В RC5 есть два независимых действия: перенести **настройки окружения** и сохранить **текст заметок**. Они не запускают приложения, не применяют оформление Windows и не заменяют полную резервную копию данных.

Функции опубликованы в [RC5](https://github.com/LosarOS/SHIFT/releases/tag/v1.0.0-rc.5). Реальные file-picker, Notes/clipboard и import/cancel сценарии прошли на Windows runner: [технический отчёт](../reports/SHIFT-RC5-VALIDATION-RU.md). Физическая Windows10/11/DPI/accessibility матрица остаётся непроверенной.

## Экспорт профиля

1. Откройте «Студия» → «Профили» и найдите профиль. Поиск учитывает имя, описание и связанное пространство.
2. Нажмите «Экспорт» на его карточке. Профиль должен содержать хотя бы один виджет.
3. Просмотрите JSON. При необходимости включите **«Включить начальный текст шаблонов заметок»**; по умолчанию он выключен.
4. Выберите «Копировать JSON» либо «Сохранить файл». Для файла используется расширение `.shiftstudio.json` и UTF-8.

Пакет содержит имя и описание профиля, типы и названия используемых виджетов, их оформление, параметры содержимого, размеры, относительные позиции и видимость. Общие определения сохраняются как общие: несколько экземпляров могут ссылаться на один шаблон.

Пакет **не включает**:

- изображения обоев и пути к ним;
- идентификаторы исходных мониторов;
- привязку к Workspace и правило автоприменения;
- текущий текст Notes, прогресс таймеров, настройки SHIFT и журнал восстановления;
- приложения, команды или исполняемые пути.

Имена, описание и выбранный начальный текст остаются обычным текстом и могут содержать личную информацию. Поле заголовка не очищается от добровольно введённых вами сведений: проверяйте весь JSON перед передачей.

Начальный текст — значение шаблона для нового экземпляра Notes. Он может отличаться от того, что сейчас написано в открытом виджете. Для текущего текста используйте отдельное действие «Сохранить заметки».

Размер пакета ограничен **2 МиБ**. Если добавление начального текста превышает лимит, соответствующий флажок недоступен и отображается объяснение; оформление остаётся доступно для экспорта без текста. Сам экспорт не меняет исходный профиль.

## Импорт профиля

1. В «Студия» → «Профили» нажмите «Импорт профиля».
2. Выберите JSON-файл или вставьте JSON в поле. Нажмите «Проверить и продолжить».
3. Просмотрите типы, названия и количество виджетов, описание и предупреждения. Измените имя нового профиля при необходимости.
4. Выберите расположение: по умолчанию видимые виджеты раскладываются на основном экране; снимите флажок, чтобы сохранить переносимые размеры и относительные позиции.
5. Нажмите «Сохранить». После этого отдельно откройте редактор для проверки содержимого и нажмите «Применить профиль», когда будете готовы.

«Назад к JSON» возвращает исходный текст для исправления; «Отмена» закрывает диалог без сохранения. Ошибка проверки или записи не должна создавать частичный набор виджетов. Сохранение использует одну транзакцию и новые идентификаторы профиля, определений и экземпляров. Существующие записи и активное окружение не перезаписываются.

После импорта привязки к мониторам сброшены. При применении окна открываются в режиме редактирования; «Поверх всех окон» и сквозной режим выключены. Автоприменение и изменение обоев не включаются. Если исходный профиль был отключён, включите его в редакторе перед применением.

Прочитайте предупреждение, если в пакете есть начальный текст заметок. Посмотреть и исправить его можно в мастерской до применения. На маленьком экране все виджеты могут не поместиться одновременно: предупреждение о тесном расположении означает, что возможны перекрытия. Уменьшите количество видимых экземпляров или настройте расположение вручную.

Поддерживается версионированный декларативный формат `SHIFT.StudioProfile`, schema 1. Неизвестные поля, повторяющиеся JSON-поля, неподдерживаемая версия, неверные ссылки, значения вне границ и файлы больше лимита отклоняются. Один пакет поддерживает 1–64 экземпляра и используемых определения. JSON не является скриптом; импорт не содержит механизма выполнения кода или загрузки ресурсов из сети.

## Сохранить заметки профиля

На карточке профиля с Notes нажмите **«Сохранить заметки»**. Перед записью откроется читаемый снимок; доступны «Копировать заметки» и «Сохранить файл».

Снимок объединяет:

- текущий текст открытых виджетов, принадлежащих выбранному активному профилю;
- сохранённый в базе текст скрытых или неоткрытых экземпляров;
- начальный текст определения, если у экземпляра ещё нет сохранённого состояния — с отдельной пометкой.

Текст каждого экземпляра сопровождается названием и идентификатором. Это позволяет различить две заметки, использующие один шаблон. Пустая сохранённая заметка остаётся пустой; начальный текст не возвращается вместо неё. Скрытые заметки включаются с пометкой. Unicode и пользовательские пробелы сохраняются.

Это **снимок на момент открытия предпросмотра**. Изменения, сделанные в виджете позднее, не появятся в уже открытом экспорте; откройте его заново. Тексты других профилей и содержимое таймеров не включаются.

Неоткрытые локальные recovery-черновики не читаются этим экспортом. Если после сбоя или конфликта на диске остался такой черновик, восстановите его через сам виджет и проверьте текст. При конфликте в меню доступны явные варианты: использовать текст окна либо оставить текст базы. До отказа от нужной версии сохраните отдельную копию.

Файл заметок — обычный **UTF-8 `.txt`**, без шифрования и без возможности автоматически восстановить конфигурацию профиля. Буфер обмена также не зашифрован и может быть доступен другим приложениям или системной истории буфера. Копирование выполняется только по вашему нажатию. Перед передачей кому-либо проверьте содержимое.

## Сочетания клавиш

Когда фокус находится в окне виджета:

| Сочетание | Действие |
| --- | --- |
| Ctrl+S | Сохранить состояние виджета сейчас |
| Ctrl+Shift+S | Сохранить текст Notes в отдельный файл |
| Shift+F10 или клавиша меню | Открыть меню, включая действия восстановления |

У таймера при конфликте доступны «Использовать состояние этого виджета…» и «Оставить состояние из базы…». Выбор требует подтверждения. Сохранение заметок и выбор версии состояния не разрешают выполнение команд Workspace.

## Что выбрать для резервной копии

| Задача | Подходящий способ |
| --- | --- |
| Передать оформление и набор виджетов | Пакет `.shiftstudio.json` |
| Сохранить читаемую копию текста | «Сохранить заметки» или экспорт из меню конкретного Notes |
| Сохранить пространства, историю и настройки SQLite | Backup в настройках SHIFT |
| Перенести все данные Studio, включая изображения и recovery-черновики | После полного выхода скопировать весь каталог данных |

Для установленной версии каталог данных — `%LOCALAPPDATA%\SHIFT`; для portable — `data\` рядом с `SHIFT.exe`. Полная копия включает `Studio/Images`, `Studio/RecoveryNotes` и `migration-backups`. Не копируйте только `shift.db` во время работы: активные изменения могут находиться в WAL.

Удаление профиля или экземпляра удаляет его runtime-данные. Экспорт оформления не сохраняет текущие заметки или прогресс таймера. Перед удалением проверьте текстовый экспорт и резервную копию, если они нужны.
